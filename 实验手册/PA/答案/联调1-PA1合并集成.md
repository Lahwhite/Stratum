## 二、接口接入

合并后需要在成员 A 的 `sdb.cpp` 中接入 B 实现的 `p`/`w`/`d`/`info w` 命令。

### 2.1 在 sdb.cpp 顶部取消注释

找到 A 预留的注释行，恢复：

```cpp
// 原来注释掉的：
// uint32_t expr_eval(const char *e, bool *success);
// 替换为正式 include：
#include "expr.h"
#include "watchpoint.h"
```

### 2.2 添加 p / w / d / info w 命令处理函数

在 `sdb.cpp` 中，在现有命令函数之后添加：

```cpp
static int cmd_p(char *args) {
    if (args == nullptr) {
        printf("Usage: p EXPR\n");
        return 0;
    }
    bool ok;
    uint32_t val = expr_eval(args, &ok);
    if (ok) printf("= 0x%08x  (%u)\n", val, val);
    return 0;
}

static int cmd_w(char *args) {
    if (args == nullptr) {
        printf("Usage: w EXPR\n");
        return 0;
    }
    wp_add(args);
    return 0;
}

static int cmd_d(char *args) {
    if (args == nullptr) {
        printf("Usage: d N\n");
        return 0;
    }
    int id = atoi(args);
    if (wp_delete(id))
        printf("Watchpoint %d 已删除\n", id);
    else
        printf("找不到编号为 %d 的 watchpoint\n", id);
    return 0;
}
```

### 2.3 更新 info 命令，支持 info w

修改 `cmd_info` 函数：

```cpp
static int cmd_info(char *args) {
    if (args == nullptr) {
        printf("Usage: info r | info w\n");
        return 0;
    }
    if (strncmp(args, "r", 1) == 0) {
        printf("%-8s 0x%08x\n", "pc", cpu.pc);
        for (int i = 0; i < 32; i++) {
            printf("%-8s 0x%08x", GPR_NAMES[i], cpu.gpr[i]);
            if (i % 4 == 3) printf("\n");
            else            printf("  ");
        }
        return 0;
    }
    if (strncmp(args, "w", 1) == 0) {
        wp_print_all();
        return 0;
    }
    printf("Usage: info r | info w\n");
    return 0;
}
```

### 2.4 将新命令注册到命令表

在 `cmd_table` 数组中追加：

```cpp
static Command cmd_table[] = {
    {"help",  "打印本帮助信息",                                cmd_help},
    {"q",     "退出 SDB",                                      nullptr },
    {"si",    "si [N]  单步执行 N 条指令（默认 1）",           cmd_si  },
    {"info",  "info r/w  查看寄存器或 watchpoint 列表",         cmd_info},
    {"x",     "x N ADDR  查看从 ADDR 起 N 个字的内存",         cmd_x   },
    {"p",     "p EXPR  对表达式求值并打印",                     cmd_p   },
    {"w",     "w EXPR  添加 watchpoint",                        cmd_w   },
    {"d",     "d N  删除编号为 N 的 watchpoint",                cmd_d   },
};
```

## 五、联调测试清单

逐条手动测试，两人一起执行：

### 5.1 基础命令

```
(sdb) help               # 列出所有 8 条命令
(sdb) info r             # 打印 pc + 32 个寄存器
(sdb) x 4 0x0            # 打印 4 个字
(sdb) si 3               # 打印 "step 3 instruction(s)..."
(sdb) q                  # 退出
```

### 5.2 表达式求值

```
(sdb) p 1+2              # = 0x00000003  (3)
(sdb) p 2*3+4            # = 0x0000000a  (10)
(sdb) p 2*(3+4)          # = 0x0000000e  (14)
(sdb) p 0xff             # = 0x000000ff  (255)
(sdb) p 1==1             # = 0x00000001  (1)
(sdb) p 1!=1             # = 0x00000000  (0)
(sdb) p 1+2==3&&4-1==3   # = 0x00000001  (1)
(sdb) p $zero            # = 0x00000000  (0)
(sdb) p $pc              # = 0x00000000  (0)
(sdb) p 1/0              # 打印除零错误，不崩溃
(sdb) p $xyz             # 打印未知寄存器，不崩溃
```

### 5.3 Watchpoint

```
(sdb) w $pc              # Watchpoint 1: $pc
(sdb) w 1+2              # Watchpoint 2: 1+2
(sdb) info w             # 列出 2 个 watchpoint
(sdb) d 1                # 删除 watchpoint 1
(sdb) info w             # 只剩 watchpoint 2
(sdb) d 99               # 找不到编号 99，有提示
```

### 5.4 异常输入鲁棒性

```
(sdb) foo                # 未知命令提示
(sdb) p                  # 缺少参数提示
(sdb) x                  # 缺少参数提示
(sdb) d                  # 缺少参数提示
```
